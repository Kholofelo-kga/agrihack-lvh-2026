AGRIHACK 2026 - SIMPLE ALLOCATOR WITH COUNTDOWN

1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Enter ten unique group names.
4. Click Randomly Allocate Topics.
5. Watch the 10-to-1 countdown; the results appear automatically.
6. Print or save results as PDF.

To update an EXISTING Netlify website:
Go to the project's Deploys page and upload the extracted site folder containing index.html, style.css and script.js together. Keep all three files in the same folder. This replaces the deployed files but preserves the existing site URL.

This system does not save results after a refresh. Print or save the official draw immediately. The countdown is presentation-only; allocation is random, not based on entry order.
